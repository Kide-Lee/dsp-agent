# 更新日志

## 1.2.381

修复恒星系查不到戴森球的问题。

- 恒星系的成员列表现在会列出该星系的戴森球；此前只列恒星、行星与黑雾巢穴，
  AI 因此无法通过恒星系发现星系里有戴森球。

- 世界区域若包含某颗恒星，也会把它的戴森球算进来。

## 1.2.380

AI 现在能理解“一片区域、一个点、一个会移动的目标”，不再需要你或它自己换算经纬度。

**新功能**

- 三个新的查询工具：`space_region`（区域）、`space_point`（定点）、`space_motion`（动点）。
  一次调用就能回答“这片产线有什么、产出多少、耗多少电”“这栋建筑属于哪个工厂、在哪”
  “那架无人机现在飞到哪了、在送什么”。
- 区域覆盖恒星系、恒星、行星、电网、工厂、太空黑雾巢穴、地面黑雾基地、戴森球、
  世界坐标长方体、行星表面矩形，以及蓝图文件；定点覆盖建筑、矿脉、植被、
  太空/地面黑雾建筑与世界/行星坐标；动点覆盖玩家、各型无人机与运输船、
  小型运载火箭、战斗无人机、战舰、太空/地面黑雾单位与垃圾块。
- 统计口径可选：时间窗（1 分钟到 100 小时）、单位（每分钟/每小时/总量），
  以及“实际统计”或“按配方算的理论值”。
- 蓝图可以直接问：列出建筑、算理论进出料与耗电、读出作者/版本/缩略图信息。
- 方位指示能直接接空间变量：说“给这片区域做个导航”即可，不用先查 id。

**改进**

- 电力查询补上蓄电池充放功率与按电网拆分的明细。
- 产线查询补上净产出、库存还能撑几分钟，以及产出/消耗两侧的完整数字。
- 建筑列表的行里带上经纬度、类别、配方、朝向与配方耗时。

**工具变化**

- 以下工具已由新工具取代并移除：`game_get_power`、`game_get_production`、
  `game_get_entities`、`game_analyze_area`、`game_get_player`。
  如果你有脚本或习惯用法依赖它们，改用 `space_region` / `space_motion` 的对应 `op`。
- 动点（无人机、运输船等）会移动，方位指示是静态箭头，对它会被明确拒绝。

## 1.1.295

多会话并行、蓝图 DSL 与工厂布局出图。

**新功能**

- **多会话并行**：多个会话可以同时回答；切到别的会话不会中断后台任务，切回后会接上已生成的正文。

- **物流站**：新增端口格表与站单体校验，供料支持 `supply=station`。
- **轮内待办**：AI 可以在当前回合维护目标清单，回合结束自动清空。
- **顾问字幕**：聊天窗关闭时，后台完成/提问等事件用游戏顾问字幕提示。

**修复**

- 已完成或跳过的游戏目标在重开后不再重新注入。
- 目的地指引右键逐个删除、清空全部定位时按游戏原生行为处理；地图标记使用当前行星的定位标记。
- 自由探索和沙盒存档里也能正常显示 AI 目标。
- 思考块流式输出时高度只增不减，不再抖动。
- 左栏会话记录改为最新一轮在前；工具页分类标签恢复分组筛选。

- 星球链接聚焦补上分步日志与半径防护。
- 兼容 0.10.35 蓝图的 `content` 字段，并校准校验器。

**变更**

- 升级 pi SDK 到 1.5.0，依赖升级到 Node 26 / TypeScript 7 / typebox 1.4 线。
- 蓝图出图器取代旧的线性链/单段布局；大产线拆张有 8 秒预算和 512 张上限。

## 1.1.247

第三方 mod 桥重做、回答可中断，以及作答面板与聊天窗的一批修复。

**新功能**

- **其他 mod 控制**：设置 → 工具 → mod 页签可逐插件开启或关闭；关闭后该插件对 AI 完全不可见。
  每个插件可以单独设权限档位（只读 / 受限 / 接管，默认受限），列表会标注适配器来源与工具数量。
- **AI 生成适配器**：AI 可以按插件的公开方法生成适配器，玩家确认后写入并立即生效；
  生成的能力每次调用都会请求确认，插件更新后版本不匹配的适配器会自动禁用。
- **中断与插话**：回答过程中可以中断当前回合，或在输入框有内容时插话；被打断的回复会保留并标注「已停止」。

**修复**

- 作答面板：选项 hover 高亮残留、题目序号不随题目变化、自定义答案输入框无法使用输入法。
- 聊天窗：中断后按钮不回切「发送」、长文本不撑开输入区、用户气泡的时间与复制按钮消失。
- 会话：切走空会话后仍留在索引里；左栏记录按标签真实字号截断，不再溢出。
- 其他 mod：适配器参数类型写法不规范会导致整轮请求失败；插件启动较晚才注册的配置项不会生成配置工具；
  设置页不刷新适配器状态。

## 0.4.0

读侧优化、受控写工具、实体链接卡片与方位指示。

**新功能**

- **丢弃/配方/存储/投料**：`game_drop_item`、`game_set_recipe`、`game_set_assembler_batch`、
  `game_take_output`、`game_feed_input`，以及存储过滤器/容量/移库/存入/取出。
  写操作仍需玩家确认；存储/投料可撤销，取成品不可撤销。
- **受控写脚本**：`run_script` 默认只读；脚本含字面量写工具时先弹一次脚本级确认，
  租约绑定脚本哈希与写工具名，结束立即释放；动态拼写写工具名会被拒绝。
- **实体链接**：回答里的 `dsp://entity/planet|building|vein/...` 可点击聚焦；
  建筑/星球/矿脉链接卡片随回答显示，支持历史回放、定位/已定位。
- **方位指示**：`game_tether_add/list/clear`，本星球多目标自绘线，跨行星用原生导航。
- **读侧优化**：`game_get_entity` 支持 `fields`/`entityIds`；`game_get_planet`
  支持矿脉群与逐矿脉分页。

**修复**

- 恢复 `game_place_marker`，保持 `game.write.v1` 工具集合兼容；标记可撤销。
- 按 design §9.1 移除不可撤销的 `game_dismantle`，避免无自动存档兜底时的破坏性操作。
- 撤销栈：不可撤销操作会占用栈顶并明确报错，不再误撤销更早的无关操作；
  `game_undo_last_write` 现在也走确认。
- 存储写入按真实容量（bans + 过滤）预检，修复背包/存储满时可能丢物品的窗口。
- 矿脉链接卡片不再在历史回放/删除回合时丢失。
- 重复提问的链接卡片按回答原文消歧，避免卡片串到别的回合。
- 行星视图聚焦与研究目标切换：写工具在行星视图/研究目标下不再失败或切错。

## 0.3.2

问答界面、受控写操作与经纬度坐标；上下文压缩可见、可撤销；sidecar 升级到 pi 1.4。

**新功能**

- **问答界面**：AI 需要玩家选择或补充信息时，聊天窗会弹出原生问答面板
  （选项 + 自定义答案），玩家回答后继续。

**修复**

  运行 sidecar 的 Node 门槛提高到 22.19。
