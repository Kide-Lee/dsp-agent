# M4j 验收：蓝图生成（KB 配方 + dsp-calc 布局）

> 需求：按玩家当前的游戏数据生成真正可用的完整产线蓝图，而不是只放末段机器或凭模型心算。

## 1. 自动化（离线）

```bash
scripts/build-mod.sh
dotnet run --project tests/ProtocolTests
cd sidecar && npm test
```

新增 `sidecar/test/blueprint-plan.mjs`（38 项）与 `sidecar/test/blueprint-tiers.mjs`（20 项）：

| 检查 | 期望 |
| --- | --- |
| 60/min 电磁涡轮阶段数 | 7（铁块/磁铁/电动机/齿轮/磁线圈/铜块/电磁涡轮） |
| 总机器数 | 29（与 `kb_plan` 一致） |
| 实际放置 | 14 台电弧熔炉 + 15 台制造台 Mk.I |
| rows=2 | 宽度下降，机器数仍为 29 |
| 300/min | 自动拆 3 张，每张约 100/min |
| 600/min | 自动拆 5 张，每张约 120/min |
| `from=smelted` | 只保留 4 个装配阶段、15 台机器；原料为铁块/磁铁/铜块；不再放熔炉 |
| `from=电动机` | 9 台机器；原料含电动机 120/min |
| 被动档位 | `save.bind.blueprintTiers` 的 mk3/蓝带/堆叠被默认采用；显式参数可覆盖；低档分拣器警告 |
| `blueprint_fs` | 31 项：pwd/cd/ls/cat/mkdir/write/rm/rmdir、默认 `IcarusII`、路径逃逸/符号链接拒绝、永久删除、write 卡片 |
| mk3 档位 | 机器数减少，装配阶段选 2305 |
| 知识库缺失 | `kb_unavailable`，不生成 |
| 绿马达别名 | 解析为电磁涡轮，结果带 `alias.source=curated/wiki` |
| 单阶段配方（只造铁块） | 明确报“至少需要两个生产阶段”，不生成空蓝图 |

`wiki-alias.mjs`（15 项）验证：蓝马达/绿马达/白糖等 curated 命中、Wiki insource + `|别称=`
解析、缓存命中不再联网、多候选不猜、Wiki 不可用时不阻断。

`blueprint.mjs`（42 项）验证：`blueprint_save` 默认写入 `IcarusII/`、可写子目录、
同名自动加序号、坏蓝图不落盘。

`pi-tools.mjs`（46 项）还验证：`blueprint_generate` 真实落盘后，卡片在 final message 之后、
idle 之前发出，并能随历史回放/删除。

## 2. 实机（待逐条过）

前置：进入存档，等状态栏显示知识库就绪；`GameMain.history.blueprintLimit != 0`。

| # | 操作 | 期望 |
| --- | --- | --- |
| 1 | 让 AI 生成「电磁涡轮 60/min」 | 7 个阶段、29 台机器；文件约 136×10 格 |
| 2 | 打开蓝图预览 | 能看到电弧熔炉、制造台、带子、爪子、物流站；不是只有末段机器 |
| 3 | 粘贴并接入铁矿/铜矿 | 各阶段有进料；最终产出接近 60/min |
| 4 | 生成「电磁涡轮 300/min」 | 返回 3 张，每张约 100/min；逐张可粘贴 |
| 5 | 生成「电磁涡轮 600/min」 | 返回 5 张，每张约 120/min；全部铺下才达到 600/min |
| 6 | `rows=2` | 布局折成 2 行，宽度明显下降，机器数不变 |
| 7 | `buildingTier=mk3` | 使用 Mk.III 制造台；机器数比 base 少 |
| 8 | 输入「蓝马达 60/min」 | 别名解析为超级磁场环；结果带 alias 来源；生成其产线 |
| 8b | 让 AI「不要从原矿开始，从铁块/钛块开始」 | 传 `from=smelted`；蓝图只含装配阶段，原料从铁块/磁铁等投入 |
| 9 | 没有解锁蓝带/集装分拣器时 | 当前默认最高档，粘贴可能被游戏拒绝；记录实际表现（档位上报待做） |
| 10 | 三输入配方（小型运载火箭） | 当前应返回明确错误或 warnings，不得声称“完整可用” |
| 11 | 带副产物配方（精炼油/氢） | 记录是否报“多副产物/多氢来源”；不要静默生成错误蓝图 |
| 12 | 卡片 | 来源「生成」、名称/产量/建筑数/占地/作者正确；点粘贴进入预览 |
| 13 | 删除该问答回合 | 卡片随回合消失；重进存档不再回放 |
| 14 | 让 AI「看看蓝图目录」/「进 IcarusII」/「读一下这张蓝图」 | `blueprint_fs` 正确列目录、切目录、返回元数据；不越出蓝图根 |
| 15 | 让 AI「在 IcarusII/测试 里存这张蓝图」 | `dir` 生效；卡片「查看详情/粘贴」能定位子目录 |
| 16 | 让 AI 删除一张测试蓝图 | 先询问；确认后永久删除；未确认时无变化 |

## 3. 已知限制

- 单张混带总线最多 3 条蓝带；高产量拆多张，卡片目前只指向第一张。
- 多产物/多副产物配方、部分三输入配方仍受 dsp-calc 布局器限制。
- 默认从原矿投入开始，不含采矿机/矿脉。
- 别名解析依赖中文 Wiki；Wiki 不可用时只走 curated 表。
