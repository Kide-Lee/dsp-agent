# 左栏标志换成预渲染「空间管理联盟」logo

> 2026-11-18。

## 为什么要改

用户给定一张现成的标志图，要求直接用它替换左栏顶部原来那套脚本生成的标志：

- 源图：https://patchwiki.biligame.com/images/dsp/3/37/oh0wg5k5duck6nmbx5g9f6zs79zohu2.png
- 1087x325 PNG，白色标题「空间管理联盟」+ 英文 `Coalition Of Space Management Organization`，左上角是蓝色扇区 + 白色星球徽记
- 仓库内留档：`docs/plans/brand-logo-source.png`，sha256 `d9b562d9de5e9777f029f1f061d92fe46e8e94dac1cd35a14dee0ddc805544a4`

旧方案是从 `Assets/Resources/UI/Textures/dsp-logo-flat-zh.png` 抠徽记、再用游戏自带锐黑字体排字。
用户要求改成直接使用这张预渲染图，脚本不再重绘任何字形或图标。

## 做了什么

1. 源图按 alpha 裁剪，去掉四周空白，得到 1019x218；像素原样保留，没有缩放、描边或加投影。
2. 写入 `dsp-game/Assets/IcarusII/Resources/brand-logo.png`，`.meta` 沿用 `console.png.meta` 的导入设置（Sprite、不压缩），guid 固定为 `6f1d0c3e9a7b45d28c4e1a5f7b6d3c92`，prefab 里的 `Image.sprite` 引用不变。
3. 生成脚本 `.scratch/logo/make_brand_logo.py`（`.scratch` 不入库）：下载地址、sha256 校验、裁边、写 meta 都在里面。

## 方向为什么不用翻转

Unity 里 Sprite 的显示行序容易被想反，这里没有靠推断，而是用 `unity_execute` 把导入后的纹理走 `Graphics.Blit` + `ReadPixels` 抽样，从上到下打了 12 行截面：
徽记（左上）出现在 `uv.y` 最大的那一行，英文行出现在 `uv.y=0`。也就是说 png 第一行就是屏幕最上一行，直接存、不翻转。

## prefab 现状

`chat-index/brand-logo`：

| 字段 | 值 |
| --- | --- |
| anchorMin / anchorMax | (0,1) / (0,1) |
| pivot | (0,1) |
| anchoredPosition | (17,-2) |
| sizeDelta | (250,53.48) |
| Image | sprite=`brand-logo`，type=Simple，preserveAspect=true，raycastTarget=false |
| layer | 5 (UI) |

尺寸按贴图宽高比算：贴图 1019x218（比例 4.6743），宽度取左栏宽度 250，高度 = 250 / 4.6743 = 53.48。
`preserveAspect=true` 是第二道保险：以后有人拉伸 rect，Image 也只按 250x53.48 居中绘制。
**改贴图尺寸或换图时，`sizeDelta` 的高度要同步改**，否则会被 preserveAspect 缩出两侧留白。

五个功能行各下移 24px（`-84 / -116 / -148 / -180 / -212`），`chat-index-scroll` 与 `chat-index-empty` 的 `sizeDelta.y` 为 `-244`。

250 宽在暗底上的实际观感：`.scratch/logo/panel-250.png`（工作副本，不入库）。
